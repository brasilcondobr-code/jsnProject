Camada de dados do projeto JSN: CPTs, taxonomias, REST e central de widgets.

== Description ==

O plugin mantém a camada de dados separada da apresentação do tema:

* CPTs `servico` e `noticia_condominio`, com taxonomias.
* Endpoints REST em `/wp-json/jsn/v1/*`.
* Central de bloqueio/desbloqueio dos widgets em Configurações > JSN Widgets.
* Padrões Gutenberg para composição de páginas.
